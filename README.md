# Indian-E-Commerce-Sales-Analysis-using-SQL

## README – Project Overview

This project analyzes an Indian e-commerce dataset containing  sales transactions, customers, and products to uncover insights into revenue trends, customer behavior, product performance, inventory, discounts, returns, cancellations, payment methods, and regional sales performance. PostgreSQL was used for data cleaning, validation, joining the datasets, and answering key business questions through SQL analysis. The analysis highlights important findings, including the strong contribution of Electronics and Platinum customers, significant revenue tied to cancelled and returned orders, slow-moving inventory, and coupon users recording a lower average order value than non-coupon users. These insights can support better decisions around inventory management, promotions, customer targeting, product performance, and revenue growth.
